# کارت ویزیت دیجیتال

| فایل | کاربرد |
|---|---|
| `index.html` | صفحه‌ی کارت ویزیت (همان آدرسی که QR به آن اشاره می‌کند) |
| `data.js` | همه‌ی اطلاعات کارت — از طریق پنل مدیریت ویرایش می‌شود |
| `admin.html` | پنل مدیریت (ورود با نام کاربری و رمز) |
| `auth.js` | هش رمز و توکن رمزنگاری‌شده‌ی گیت‌هاب — دستی ویرایش نکنید |
| `photo.jpg` | عکس پروفایل (بعد از آپلود از پنل ساخته می‌شود) |

## راه‌اندازی روی GitHub Pages
1. همه‌ی فایل‌ها را در یک مخزن (Repository) آپلود کنید.
2. در مخزن: **Settings › Pages › Source: Deploy from a branch** و شاخه‌ی `main` را با پوشه‌ی `/ (root)` انتخاب کنید.
3. سایت روی `https://USERNAME.github.io/REPO/` بالا می‌آید و پنل مدیریت روی `.../admin.html`.

## اولین ورود به پنل
1. وارد `admin.html` شوید.
2. یک **Fine-grained token** بسازید: **Settings › Developer settings › Personal access tokens › Fine-grained tokens**
   - در Repository access فقط همین مخزن را انتخاب کنید.
   - در Permissions، گزینه‌ی **Contents** را روی **Read and write** بگذارید.
3. توکن را در پنل وارد کنید. پنل آن را با رمز شما رمزنگاری می‌کند و در `auth.js` ذخیره می‌کند. این کار فقط یک بار لازم است.

بعد از هر «ذخیره و انتشار»، حدود یک دقیقه طول می‌کشد تا GitHub Pages نسخه‌ی جدید را منتشر کند.
اگر توکن منقضی شد، از منوی پنل گزینه‌ی «اتصال مجدد گیت‌هاب» را بزنید.
